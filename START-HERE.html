NiSource: try CVAT on your own machine

This folder runs the demo you saw, on open-source CVAT v2.82.0, with a sample project ready to explore: 100 photos, the labels, a model's first-pass polygons and a 20-photo answer key.

Start in three steps

1

Check you have what it needs

  • Docker Desktop, open and running
  • git, and Python 3.10 or newer (or uv)
  • About 10 GB of free disk, on Mac, Linux or Windows
2

Open a terminal in this folder and run one command

bash start.sh

It starts CVAT, loads the project, prints the quality scores and opens your browser. The first run downloads CVAT and can take 10 minutes or more. It is safe to run again.

3

Sign in

Go to http://localhost:8080 and sign in as demo. The password is printed at the end of step 2 and saved in the file .demo-credentials in this folder. It only exists on your machine.

On Windows

Run it inside WSL 2 (Ubuntu). In Docker Desktop, turn on Settings > Resources > WSL integration for your distribution. Unzip this folder inside your WSL home folder (for example ~/cvat-demo), not on the C: drive, then run the command above in the Ubuntu terminal. If Python complains about venv: sudo apt install python3-venv. The browser link works from Windows as usual.

Using Claude Code or another AI coding assistant? Open this folder in it and say "set up this demo". The file CLAUDE.md tells it what to do.

When you are done

Stop CVAT and keep your work:

bash scripts/stop.sh

Stop CVAT and delete everything it stored:

bash scripts/stop.sh --delete

If something goes wrong

  • "Docker is installed but not running": open Docker Desktop, wait until it has started, and run bash start.sh again.
  • CVAT does not come up: port 8080 must be free. docker logs cvat_server shows the reason.
  • Start over: bash scripts/stop.sh --delete, then bash start.sh.
